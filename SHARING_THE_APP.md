# Sharing the Application

When you are ready to share "Cell's and Cell - Mobile Compatibility Finder" with another person, **you do NOT need to give them your source code**. 

You only need to provide them with the standalone Windows installer (`.exe` file) generated by the build process.

## How to generate the distributable file

1. Double-click the **`build.bat`** file in your project folder.
2. Wait for the process to complete (it will build Next.js, compile Electron, and package the app).
3. Upon success, a folder window will automatically open pointing to `out\make`.

## What file to share

Navigate to:
```
out\make\squirrel.windows\x64\
```
Inside this folder, you will find a file named:
**`Mobile Compatibility Finder Setup.exe`**

**This is the ONLY file you need to share.**

## What happens when they run it?

When the recipient double-clicks the `Setup.exe` file on their Windows machine:
- The app installs silently in the background (to `%LocalAppData%\Mobile Compatibility Finder`).
- It automatically creates a shortcut on their Desktop and Start Menu.
- The app launches immediately.
- A local SQLite database is automatically created on their machine the first time the app starts.

## Why is it secure?

- **No source code:** Your `.tsx`, `.ts`, and `.env.local` files are not exposed as raw text. They are bundled and packed into an `.asar` archive.
- **No dependencies needed:** The recipient does NOT need to have Node.js, npm, or Git installed. The Electron runtime (Chromium + Node.js) is bundled directly into the `.exe`.

## Portable Version

If the recipient prefers not to install the app, you can share the portable `.zip` file located at:
```
out\make\zip\win32\x64\mobile-compatibility-finder-win32-x64-1.0.0.zip
```
They can simply extract the ZIP folder and run the `.exe` inside it.
